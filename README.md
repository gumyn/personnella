# Personnella

Petit jeu de navigateur autour de Milo, un personnage dessine a la main.

Le jeu propose 15 niveaux avec des mecanismes varies pour faire decouvrir la logique et des effets de physique simples : glace, vent, marees, ressorts, aimants, contrepoids, gravite, flottabilite, miroirs, convoyeurs et portails.

## Jouer en local

```bash
cd jardin-de-papier
python3 -m http.server 8765
```

Puis ouvrir `http://localhost:8765/`.

## Tests

```bash
node jardin-de-papier/tests/worlds.cjs
```
